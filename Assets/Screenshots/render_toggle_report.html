조명 끄기, 최적화 켜기: 무엇이 달라졌나

F3/F4는 모든 조명과 포스트 프로세싱을 끄고 복원합니다. O/P는 런타임 최적화를 적용하고 되돌립니다. 아래 수치는 GameScene 공포 숲 맵을 Unity 에디터 Play 모드에서 측정한 값입니다.

드로 콜·SetPass·삼각형의 범위 표기는 몇 초 간격으로 읽은 두 값입니다. 씬이 계속 움직이므로 값이 조금씩 변합니다. 출처: get_performance_stats와 게임 내 ProfilerRecorder 오버레이.

해석

  • 프레임이 CPU에 묶여 있습니다. 모든 상태에서 CPU 메인 스레드는 약 9ms로 비슷합니다. F3으로 GPU 작업을 줄이면(−67%) 프레임 시간이 줄지만, 약 12ms의 CPU 하한은 움직이지 않았습니다. O의 이득이 약 3%에 그친 이유입니다.
  • 조명과 포스트가 지오메트리·GPU 비용 대부분을 차지합니다. 조명을 끄면 URP가 그림자 패스를 건너뛰어 드로 콜이 72%, 삼각형이 80% 줄어듭니다. 대부분 조명 48개와 캐스케이드의 섀도맵 재렌더링 비용입니다.
  • O는 GPU만 줄이고 CPU는 줄이지 못했습니다. 조명과 그림자 캐스터가 줄어 삼각형이 약 1/3 감소했습니다. 그래도 드로 콜이 약 3,600개 남아 CPU가 계속 바쁩니다.
  • 남은 가장 큰 개선(미적용): 정적 배칭, GPU 인스턴싱, 맵 메시 병합으로 드로 콜을 줄이는 것입니다. CPU 병목을 직접 겨냥합니다.

화면

스크린샷은 게임이 실행되는 중 서로 다른 시점에 캡처했으므로 카메라와 좀비 위치가 동일하지 않습니다.

F3: 무엇이 꺼지나

조명

  • 모든 Light 컴포넌트 비활성화(씬에 48개, Directional Light 포함). 이후 생성되는 조명도 0.5초마다 찾아서 끕니다.
  • 환경광·반사 강도를 0으로 설정.

포스트 프로세싱

  • 모든 Volume 비활성화: 비네트, Color Adjustments, 필름 그레인, 톤매핑, 색수차, 화이트 밸런스, Shadows/Midtones/Highlights, 블룸, 글로벌 볼륨.
  • 카메라 포스트 프로세싱과 안티앨리어싱 끔.
  • 화면 공간 앰비언트 오클루전(SSAO)과 ColossusGlitch 풀스크린 패스를 포함한 모든 렌더러 피처 비활성화.

F4는 모든 항목을 F3 이전 상태로 복원합니다.

O: 무엇을 최적화하나

조명과 그림자

  • 그림자 거리 45 → 25, 캐스케이드 4 → 2.
  • 메인 섀도맵 4096 → 1024, 추가 조명 섀도맵 2048 → 512.
  • 포인트/스팟 조명 그림자 제거.
  • 카메라에서 30m 넘게 떨어진 포인트/스팟 조명 비활성화(0.5초마다 재검사). 활성 조명 48 → 13.
  • 오브젝트당 추가 조명 4개로 제한, 픽셀 라이트 2개.

렌더링과 에셋

  • HDR 끔, 렌더 스케일 0.85.
  • LOD 바이어스 0.6, 이방성 필터링 끔, 소프트 파티클 끔, 실시간 반사 프로브 끔, 2본 스키닝.

스크립트

  • 애니메이터를 화면 밖에서 완전히 컬링.
  • LightFlicker 비활성화로 프레임마다 도는 펄린 노이즈 갱신 제거.

P는 모든 값을 복원합니다. P 이후 확인한 값: 그림자 거리 45, MSAA, 렌더 스케일 1, HDR 켜짐, 캐스케이드 4. 디스크의 URP 에셋은 수정되지 않았습니다(git 변경 없음).

측정의 한계

  • Player 빌드가 아니라 에디터에서 Game 뷰 1280×720으로 측정했습니다. 에디터 오버헤드로 CPU 시간이 부풀려질 수 있으므로, 결정 전에 빌드에서 다시 측정하세요.
  • O와 F3을 동시에 켠 조합은 측정하지 않았습니다.
  • GPU 프레임 시간은 상태당 한 번 샘플링했고 값이 흔들렸습니다(O에서 0으로 읽힌 값 하나는 제외). GPU 수치는 대략적인 값으로 보세요.
  • 렌더 스케일 0.85와 HDR 끔은 화면을 약간 부드럽게 하고 색 범위를 바꿉니다. O의 시각적 비용입니다.
  • 드로 콜과 삼각형 수에는 그림자 패스가 포함되므로 조명을 제거하면 크게 줄어듭니다.
